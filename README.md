# Overtime - Late Train PWA

Upload all contents of this folder to the root of `robhuk/xcdelayappstaff` and commit to the GitHub Pages branch. This package does not deploy itself.

Includes PWA manifest, service worker, CrossCountry-themed icons, mobile form, local form auto-save, three-digit numeric delay field, operational delay reasons, custom Other reason, revised book-off calculation, and email/copy actions.

Subject: `Late book of request from HEADCODE on DD/MM/YY`

Body uses the supplied Train Crew Resources wording. The delay minutes are emphasized with Markdown bold markers in copied report text. `mailto:` email drafts are plain text and cannot reliably apply rich-text bold formatting.

iPhone: open the published site in Safari → Share → Add to Home Screen. Visit once online first to cache the app for offline use.


Email formatting: generated email uses plain text throughout, including the delay minutes, for compatibility with standard email drafts.


Delay reason list expanded to include following late running services and additional train, infrastructure, signalling, staffing, passenger, security, and weather-related operational causes. Custom Other reason remains supported.
